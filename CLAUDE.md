# CLAUDE.md
## Stack
Next.js (App Router), TypeScript, plain CSS, Supabase (auth + database), deployed on Vercel.
## Commands
Assumed defaults for a standard Next.js project — confirm against package.json and correct this section if different: `npm run dev` (local dev server), `npm run build` (production build), `npm run lint` (lint check).
## Never
- Add a dependency without asking first.
- Edit .env or any environment variable.
- Change auth configuration without saying what is changing and why.
- Create new top-level folders.
## Conventions
Plain CSS only, no CSS framework or component library. Keep components in the existing App Router file structure. No real personal data anywhere in the app — fake names and fake content only.
